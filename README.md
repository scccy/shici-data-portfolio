# 施辞｜大数据开发工程师作品集

这是一个独立的静态作品集网站，共 15 页，包含个人简介和游戏经营数据平台项目。它不包含应聘岗位理解与匹配内容，也不包含其他项目页面、原始截图目录、面试文档或 PPT 文件。

## 本地预览

打开 `site/index.html`，使用方向键或页面上的按钮翻页。

## 发布到 GitHub Pages

1. 将本目录中的文件作为一个新 GitHub 仓库的根目录内容。
2. 在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。
3. 推送到 `main` 分支，或在 Actions 中手动运行 `Deploy public portfolio to GitHub Pages`。
4. 部署成功后，从仓库 Settings → Pages 查看公开网址。

工作流只上传 `site/`。项目截图采用当前展示版本；公开发布后任何人都可访问。
